# Validation method

The completed setup evidence is recorded here after publication and installation. Reproducible checks are `python scripts/validate.py`, the bundled Codex `quick_validate.py`, `python -m unittest discover -s tests -v`, and `python scripts/verify-installation.py --native`.

Activation fixtures cover generic frontend, React, Angular, contextual state placement, Vue, Svelte, and backend-only negative controls. Evaluate semantic relevance using the actual installed name/description and router; native discovery confirms availability, not deterministic model selection. A description evaluation is an emulation unless a real Codex model run is explicitly recorded.
